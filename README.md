# Quantum Latent Consistency Models (QLCM) — v2

Research workspace for a hybrid quantum-classical consistency-model approach
to few-step synthetic image generation, targeting a peer-reviewed quantum
machine learning venue.

This is a restart. The first iteration is archived in `v1/` (see
`v1/README.md`) — it has a usable core result but accumulated some
methodological inconsistencies from being extended experiment-by-experiment
without an upfront design. v2 starts from an explicit research design agreed
on before running anything, worked out collaboratively and recorded here as
it firms up.

Status: research design in progress. Nothing has been implemented yet.
